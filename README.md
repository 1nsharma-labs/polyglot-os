## 🏛️ What is Polyglot-OS?

Software engineering today spans dozens of runtime environments and ecosystems. 

**Polyglot-OS** unifies languages into a single queryable intelligence matrix:
1. **50+ Languages Indexed:** Compare systems languages (Rust, C++, Zig), dynamic scripting (Python, JavaScript), functional (Haskell, Elixir, Clojure), web3 smart contracts (Solidity, Cairo, Move), and Indic computing pseudo-code.
2. **Zero-Token Syntax Idiom Transpiler:** Instant pattern translations (function definitions, async HTTP, error handling, memory allocation) without burning LLM tokens.
3. **Architecture & Memory Profiling:** Compare garbage collection, borrow checking, reference counting, and raw pointer management.
4. **Native Stdio MCP Server:** Exposes language intelligence directly to Cursor, Claude Desktop, and Antigravity.

## ⚡ Quickstart

### Instant CLI Execution (`npx`)

```bash
# Check polyglot matrix status
npx polyglot-os status

# List all indexed languages
npx polyglot-os list

# Inspect language architecture
npx polyglot-os info rust

# Output idiomatic syntax pattern
npx polyglot-os transpile functionDef rust
```

### Local Setup & Testing

```bash
git clone https://github.com/1nsharma-labs/polyglot-os.git
cd polyglot-os

# Run automated tests
npm test

# Start Model Context Protocol (MCP) server
npm run mcp
```

## 🔌 Model Context Protocol (MCP) Integration

Connect Polyglot-OS to Cursor, Claude Desktop, or Antigravity:

```json
{
  "mcpServers": {
    "polyglot-os": {
      "command": "node",
      "args": ["/path/to/polyglot-os/core/src/mcp/server.js"]
    }
  }
}
```

Exposed MCP Tools:
- `polyglot_list`: Enumerate all indexed languages.
- `polyglot_info`: Retrieve deep technical specs (paradigm, typing, GC, compile target).
- `polyglot_transpile`: Translate idiom syntax patterns across languages.
